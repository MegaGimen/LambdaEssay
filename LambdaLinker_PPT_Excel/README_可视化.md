# PPT差异对比可视化工具使用指南

## 📋 功能概述

这个工具可以自动对比两个PPT文件的差异，并生成美观的可视化报告，包括：

- ✅ **HTML报告**：带有现代化UI设计的网页报告，适合在浏览器中查看
- ✅ **Markdown报告**：纯文本格式，方便版本控制和文档集成

## 🚀 快速开始

### 1. 准备PPT文件

将需要对比的两个PPT文件放在项目目录下：
- `a.pptx` - 第一个PPT文件
- `b.pptx` - 第二个PPT文件

### 2. 运行对比程序

```bash
# 激活虚拟环境（如果还没激活）
.\venv\Scripts\activate

# 运行测试脚本
python run_test.py
```

### 3. 查看报告

程序运行完成后，会在当前目录生成两个报告文件：

- **`diff_report.html`** - HTML可视化报告
- **`diff_report.md`** - Markdown文本报告

直接双击 `diff_report.html` 或在浏览器中打开即可查看美观的可视化报告！

## 📊 报告内容说明

### 1. 文件信息
显示被对比的两个PPT文件名称

### 2. 统计信息
- 段落数对比
- 字符数对比
- 其他统计指标

### 3. 关键差异摘要
以列表形式展示主要的差异点，每项都是一句简洁的描述

### 4. 差异分析
深度分析这些差异的含义和影响，解释变更背后的意图

### 5. 详细变更
按变更类型分类展示：
- ➕ **新增** - 文档B新增的内容
- ➖ **删除** - 从文档A删除的内容
- 🔄 **修改** - 被修改的内容
- ↔️ **移动** - 位置或结构调整

## 🎨 HTML报告特点

HTML报告采用现代化设计，包含：

- **渐变色主题**：紫色系渐变，视觉效果优雅
- **响应式布局**：支持PC和移动设备
- **卡片式设计**：信息分块清晰，易于阅读
- **交互效果**：鼠标悬停时有动画效果
- **颜色编码**：不同类型的变更使用不同颜色标识
  - 🟢 新增 - 绿色
  - 🔴 删除 - 红色
  - 🟡 修改 - 黄色
  - 🔵 移动 - 蓝色

## 🔧 自定义设置

### 修改PPT文件路径

编辑 `run_test.py` 文件的第48-49行：

```python
ppt_a = os.path.join("your_file_a.pptx")
ppt_b = os.path.join("your_file_b.pptx")
```

### 修改输出报告名称

在 `run_test.py` 的第91-95行修改输出文件名：

```python
html_path = generate_html_report(result, ppt_a, ppt_b, "custom_report.html")
md_path = generate_markdown_report(result, ppt_a, ppt_b, "custom_report.md")
```

## 📝 环境要求

- Python 3.8+
- 已安装所有依赖包（见 `requirements.txt`）
- 已配置 `.env` 文件中的LLM API密钥

## 💡 使用技巧

1. **批量对比**：可以编写脚本循环调用，对比多组PPT文件
2. **集成CI/CD**：将报告生成集成到持续集成流程中
3. **版本追踪**：定期生成报告并归档，追踪文档演变历史
4. **团队协作**：HTML报告可直接分享给团队成员查看

## 🐛 常见问题

### Q: 中文显示乱码怎么办？
A: 这是终端编码问题，不影响生成的HTML和MD文件。报告文件中的中文是正常显示的。

### Q: 如何修改报告的样式？
A: 编辑 `visualizer.py` 文件中的 CSS 样式部分即可自定义颜色、字体等。

### Q: 可以对比其他格式的文件吗？
A: 目前主要支持PPT，但代码结构设计支持扩展到Word、Excel等其他Office文档。
